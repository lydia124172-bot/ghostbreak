瑄品集選上線網址：shine.bafuholdings.com

這是八斧牛排、麋鹿網同一個網域底下的另一個子網域。
牛排仍是 steak.bafuholdings.com，麋鹿網仍是 moose.bafuholdings.com，不會被改到。

=== 第一步：Render 部署 ===
1. 登入 render.com
2. New → Web Service（或 Blueprint 選 ShinePiece/render.yaml）
3. 連接同一個 GitHub repo
4. Root Directory 填：ShinePiece
5. Build Command：npm install
6. Start Command：npm start
7. Health Check Path：/api/health
8. 在 Environment 設定：
   - BASE_URL=https://shine.bafuholdings.com
   - DATA_DIR=/var/data
   - INQUIRE_EMAIL=lydia3530@gmail.com
   - RESEND_FROM=Shine Piece <noreply@bafuholdings.com>
   - RESEND_API_KEY（從本機 ShinePiece/.env 複製，不要填到 GitHub）
   - ADMIN_PASSWORD（與本機後台相同）
9. 加 Persistent Disk：1GB，掛載 /var/data（存月刊內容、訂單、商品照片）
10. Deploy 完成後，Render 會給一個網址如 xxx.onrender.com
    先打開確認是瑄品集選封面，不是麋鹿網或牛排

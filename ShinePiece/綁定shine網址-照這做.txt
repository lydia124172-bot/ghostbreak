瑄品集選 — 綁定 shine.bafuholdings.com（照順序做）

這是八斧牛排、麋鹿網同一個網域底下的另一個子網域。
牛排仍是 steak.bafuholdings.com，麋鹿網仍是 moose.bafuholdings.com，不會被改到。

【前提】Render 上 shine-piece 服務狀態要是 Live（綠色）
      先打開 Render 給的 xxx.onrender.com 確認是瑄品集選封面

========================================
A. Render 加自訂網址
========================================
1. 登入 https://dashboard.render.com
2. 左邊點服務「shine-piece」（不要點 mooseweb、buff-steak 或 ghostbreak）
3. Settings → Custom Domains
4. 輸入：shine.bafuholdings.com
5. 點 Add
6. 記下 Render 顯示的 CNAME，例如：
   CNAME  shine  →  shine-piece-xxxx.onrender.com

========================================
B. Cloudflare 加 DNS
========================================
1. 登入 https://dash.cloudflare.com
2. 選網域 bafuholdings.com
3. DNS → Records → Add record
4. 填：
   Type（類型）    CNAME
   Name（名稱）    shine
   Target（目標）  貼上 Render 給的 onrender.com（不要 https://）
   Proxy status    橘色雲 Proxied 可以開
5. Save

========================================
C. 等待生效（5～30 分鐘）
========================================
1. 打開 https://shine.bafuholdings.com
2. 打開 https://shine.bafuholdings.com/api/health
3. 開播前列印 QR：https://shine.bafuholdings.com/qr
   手機掃進去會到本月專區，不是本機 127.0.0.1

本機開發仍用：啟動網站.bat → http://127.0.0.1:3003

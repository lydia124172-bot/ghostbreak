How SMS character limits work

A standard text message uses GSM-7 encoding when your text is plain ASCII plus common European symbols. One segment holds 160 characters. Extended symbols like | ^ € { } [ ] ~ \ count as two characters.

If your message includes emoji, Chinese, or most non-Latin scripts, carriers switch to UCS-2 encoding. One segment holds only 70 characters — so Chinese texts hit the limit much faster.

Multipart SMS (multiple segments)

Longer messages are split into multiple segments. Each extra segment has a small header, so the per-segment limit drops:

  • GSM-7 multipart: 153 characters per segment
  • UCS-2 multipart: 67 characters per segment

Carriers often bill per segment, not per message — so a 200-character English text costs two segments, and a 80-character Chinese text may cost two UCS-2 segments.

GSM-7 vs UCS-2 quick reference

  • GSM-7 — English, numbers, basic punctuation · 160 / 153 per segment
  • UCS-2 — Emoji, Chinese, Japanese, Korean, Arabic · 70 / 67 per segment
